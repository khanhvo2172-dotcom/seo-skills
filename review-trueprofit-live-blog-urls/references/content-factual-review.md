# Optional Content and Factual Review

Read this reference only when the user explicitly requests content or factual review.

## Checks

- Verify time-sensitive claims, prices, policies, platform rules, product capabilities, dates,
  benchmarks, and statistics against current primary or authoritative sources.
- Check whether cited external sources actually support the nearby claim.
- Detect material contradictions between the introduction, Quick Recap, body, conclusion, and
  FAQ answers.
- Flag unsupported superlatives, rankings, precise performance claims, and prescriptive
  thresholds when the article presents them as facts.
- Identify significant promised coverage that the body does not deliver.
- For tool and app mentions, check pricing and plan limits on the provider's official pricing
  page, and availability and integrations on official product pages or app listings.
- For statistics, check the original source, date, and where relevant geography, sample and
  definition. Flag estimates, single examples or category benchmarks presented as universal facts.
- Flag TrueProfit claims that overstate its capabilities or present it as a substitute for an
  unrelated tool.
- If the user is weighing a performance problem, separate likely indexing delays from
  content-quality issues before recommending content changes.

Use web research for current or unstable information. Prefer official documentation, first-party
policy pages, public datasets, and original research. For technical claims, use primary sources.
State clearly when a conclusion is an inference.

## Reporting

Report only material, actionable issues. For each issue provide:

1. the affected claim or section;
2. what is inaccurate, unsupported, contradictory, or incomplete;
3. the supporting source;
4. a suggested replacement sentence when a direct rewrite would help.

Follow the content manager's audit rules (October 28, 2026): propose the smallest edit that fixes
each problem, keep accurate and useful copy and the existing outline, and never suggest a
wholesale rewrite. If a material claim has no reliable source, or official sources disagree, say
so and ask the user rather than proposing replacement wording. End the pass with one line naming
any sections checked and intentionally left unchanged.

Keep this pass separate under `Content and factual issues`. Do not expand it into general copy
editing or an internal-link audit.
