# last30days

The upstream [`last30days`](https://github.com/mvanhorn/last30days-skill) research skill (MIT, © Matt Van Horn), vendored here unmodified at **v3.21.1**.

Invoked as `/last30days <topic>`. Researches what people actually said about any topic in the last 30 days across Reddit, X, YouTube, TikTok, Instagram, Hacker News, Polymarket, GitHub, and the web, then synthesizes the community voice into a ranked brief.

## Relationship to `last30days-mail`

`last30days-mail/` in this repo is a fork of this skill that *also* folds your own email inbox in as a private, first-party source. That fork contains a full copy of this engine plus the mail patch, so this folder is the clean, mail-free baseline for anyone who wants the original behavior.
